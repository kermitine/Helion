# Helion

RobStride control tooling for a Raspberry Pi using the official USB-CAN adapter
and a local web dashboard.

The current project is Pi-focused:

- `raspi/` contains the RobStride USB private-protocol command-line tool, web
  dashboard, install script, and GitHub update script.
- `motorbridge-main/` is the reference MotorBridge code and documentation kept
  for comparison and future integration work.

Start with [raspi/README.md](raspi/README.md) for the fresh Raspberry Pi setup,
dashboard install, USB adapter checks, and update flow.
