# Helion

RobStride control tooling for a Raspberry Pi using SocketCAN and a local web
dashboard.

The current project is Pi-focused:

- `raspi/` contains the SocketCAN command-line tool, web dashboard, CAN setup,
  install script, and GitHub update script.
- `motorbridge-main/` is the reference MotorBridge code and documentation kept
  for comparison and future integration work.

Start with [raspi/README.md](raspi/README.md) for the fresh Raspberry Pi setup,
CAN bring-up, dashboard install, and update flow.
